# Мой канбан

Небольшая адаптивная канбан-доска для личных дел. Работает полностью в
браузере и хранит данные в `localStorage`.

## Возможности

- Создание, редактирование и удаление карточек: заголовок, описание, срок и приоритет.
- Добавление, переименование и удаление пустых колонок.
- Перетаскивание карточек между колонками и смена порядка внутри колонки.
- Поиск карточек по заголовку и описанию.
- Переименование доски.
- Карточки, колонки и название доски сохраняются после перезагрузки страницы.

## Запуск

```bash
yarn install
yarn dev
```

Открыть <http://localhost:3000>.

## Разработка

```bash
yarn lint
yarn typecheck
yarn build
```

Данные доски живут только в браузере и никуда не отправляются. Чтобы сбросить демо-доску, удалите запись `my-kanban-board` из local storage браузера.

Попробовать на <https://gnamik-kanban.vercel.app>
